# TBS Kliniek v2 &bull; 2D Isometrische Virtuele RP Wereld

Een moderne, schone 2D isometrische multiplayer browser game geïnspireerd op de klassieke sociale mechanieken van Habbo Hotel, maar in een rauw, volwassen bajes en TBS Kliniek universum.

## Kenmerken
- **100% Schone Eigen Code**: Geen legacy Java emulators, geen Flash, geen gelekte Sulake bestanden.
- **Hardware-versnelde HTML5 Canvas**: 60 FPS vloeiende graphics op zowel desktop als mobiele touchscreens.
- **Realtime WebSockets**: Directe synchronisatie van spelersposities, chatballonnen en meubels.
- **Cloudflare Ready**: Standaard WSS over poort 443 met 20-seconden hartslag pings (geen timeouts, geen IP lekken).
- **Kamerbouwer & Meubels**: Plaats, draai en stapel meubels op het isometrische tegelrooster.
- **De Kliniek Navigator**: Schakel tussen eigen cellen, openbare afdelingen (Luchtplaats, Kantine) en bende-hoofdkwartieren.

## Lokale Installatie & Starten
```bash
npm install
npm start
```
Open vervolgens in je browser:
`http://127.0.0.1:3000`
